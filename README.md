# OIV Global - Hero Page

This repository contains the main page (Hero Section or Landing Page) for **OIV Global** (International Organization of Volunteers), a platform that connects passionate individuals with volunteering opportunities around the world.

**🔗 Live Demo:** [View Live Project](https://devcacl.github.io/OIV-HERO-PAGE/)

## 🚀 Features

- **Modern & Attractive Design**: Implementation of *glassmorphism*, vibrant gradients, and subtle micro-interactions.
- **Fully Responsive**: Adaptable to mobile devices, tablets, and desktops using CSS Media Queries.
- **Integrated Background Video**: Dynamic visual element in the header (with a fallback poster).
- **Partners Section**: Cleanly displays the institutions that back the organization (with a color effect on hover).
- **Impact Statistics**: Clear visualization of the global reach (volunteers, countries, projects).
- **Accessibility & HTML Semantics**: Use of HTML5 tags and ARIA attributes for better browser interpretation.

## 🛠️ Technologies Used

- **HTML5**: Structure and semantics.
- **CSS3 (Vanilla CSS)**: Styling, Flexbox/Grid layouts, animations, and native CSS variables (Custom Properties).
- **JavaScript (Vanilla)**: Minimal interaction to handle the responsive hamburger menu.
- **Font Awesome**: Iconography.

## 💻 Installation & Usage

Since this is a static Front-end project, no dependencies are required to be installed.

1. Clone the repository:
   ```bash
   git clone https://github.com/devcacl/OIV-HERO-PAGE.git
   ```
2. Navigate to the project directory.
3. Open the `index.html` file in your web browser (or use an extension like *Live Server* in VSCode for auto-reloading).
